# AutoTranslate modular CDN structure

Upload this complete directory structure to the repository root and run only `AutoTranslate_Master_Loader.js`.

- `header/`: Auto Fetch, token, total earnings, header UI.
- `help-tools/`: Auto Fill, Copy, Paste, L3, helper buttons.
- `ai-label/`: Gemini prompt and single/batch AI label calls.
- `segment-helper/`: Start, End, create/select segment, seek to segment end.
- `video/`: Auto Follow for the playhead.

For later versions, append the version to folder/file names and update `FEATURE_FILES` in the master loader. Keep the listed order unchanged.
